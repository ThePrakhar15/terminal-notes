# Local-First Terminal Note Taking App

A terminal-inspired note-taking application built using the MERN stack.

## Current Progress

- ✅ Requirements Gathering
- ✅ High-Level Design (HLD)
- ✅ Low-Level Design (LLD)

## Planned Features

- User Authentication
- CRUD Notes
- Search Notes
- Folders
- Tags
- Pin & Archive Notes
- Markdown Support
- Terminal UI

## Tech Stack

- React + Vite
- Node.js
- Express
- MongoDB
- JWT Authentication
